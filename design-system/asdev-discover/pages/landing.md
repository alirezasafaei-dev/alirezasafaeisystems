# Landing overrides

Apply `../MASTER.md` first. This page adds only the following Discover landing differences.

- Use RTL as the default for Persian editorial content and LTR only for URLs, product names, technical tokens, and explicitly English content. Keep direction changes local to the content that needs them.
- Lead with the resource title, source, and concise value proposition; cards place topic/context before secondary metadata and keep the lead card visibly distinguished without visual noise.
- Preserve keyboard-visible focus for search, filters, cards, and CTAs. Filters use semantic button chips and reflow instead of clipping at zoom or narrow widths.
- Make every card, CTA, and filter target at least 44px. Use subtle 150–250ms feedback only and present the final state without animation under reduced motion.
- Prefer the trust-blue/orange system from the Master. Do not introduce AI-purple/pink cliché gradients or decorative motion that competes with editorial scanning.
